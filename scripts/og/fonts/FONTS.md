# Fonts used by the Open Graph generator

Outlined to SVG paths at build time; none is shipped to the browser.

- `IBMPlexMono-500.ttf` — IBM Plex Mono Medium, SIL Open Font License 1.1 (https://github.com/IBM/plex).
- `SpaceGrotesk-500.ttf` — Space Grotesk Medium, SIL Open Font License 1.1 (https://github.com/floriankarsten/space-grotesk).
- `DejaVuSans.ttf` — DejaVu Sans, DejaVu Fonts License (Bitstream Vera derivative, https://dejavu-fonts.github.io/License.html). Fallback for motif glyphs IBM Plex Mono and DejaVu Sans Mono lack (braille in Canopy's motif).
