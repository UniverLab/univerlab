# Fonts used by the Open Graph generator

Outlined to SVG paths at build time; none is shipped to the browser.

- `IBMPlexMono-500.ttf` — IBM Plex Mono Medium, SIL Open Font License 1.1 (https://github.com/IBM/plex). License: `OFL-IBMPlexMono.txt`.
- `OldStandardTT-Bold.ttf` — Old Standard TT Bold, SIL Open Font License 1.1 (https://fonts.google.com/specimen/Old+Standard+TT). License: `OFL-OldStandardTT.txt`. Display face.
- `EBGaramond-Regular.ttf` — EB Garamond Regular, SIL Open Font License 1.1 (https://fonts.google.com/specimen/EB+Garamond). License: `OFL-EBGaramond.txt`. Body face.
